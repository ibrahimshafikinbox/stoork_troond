📱 Troond Chat System — Backend API & Database Spec

E-Commerce Platform Version 1.0 English Spec • Target: Backend Engineering Team

1. Overview & Flow

The Troond Chat system facilitates direct 1-on-1 communication between an authenticated Customer and a Seller / Merchant.

  • Supported Message Types:
    • text: Standard text messages.
    • product: Contextual inquiry attached to a specific product (ID, title, price, photo).
    • image: Photos uploaded from mobile camera or gallery (JPG, PNG, WebP).
    • voice: Voice notes (M4A, AAC, MP3) with duration and audio waveform.
  • Message Lifecycle: sending → sent → delivered → read

2. Database Schema (MySQL / PostgreSQL)

Table 1: chats

CREATE TABLE `chats` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `customer_id` BIGINT UNSIGNED NOT NULL,
  `seller_id` BIGINT UNSIGNED NOT NULL,
  `product_id` BIGINT UNSIGNED NULL DEFAULT NULL COMMENT 'Initial product context if started from product page',
  `last_message_id` BIGINT UNSIGNED NULL DEFAULT NULL,
  `last_message_at` TIMESTAMP NULL DEFAULT NULL,
  `unread_customer_count` INT UNSIGNED NOT NULL DEFAULT 0,
  `unread_seller_count` INT UNSIGNED NOT NULL DEFAULT 0,
  `status` ENUM('active', 'archived', 'blocked') NOT NULL DEFAULT 'active',
  `created_at` TIMESTAMP NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at` TIMESTAMP NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `unique_chat` (`customer_id`, `seller_id`),
  INDEX `idx_customer_inbox` (`customer_id`, `last_message_at` DESC),
  INDEX `idx_seller_inbox` (`seller_id`, `last_message_at` DESC)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

Table 2: chat_messages

CREATE TABLE `chat_messages` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `chat_id` BIGINT UNSIGNED NOT NULL,
  `sender_id` BIGINT UNSIGNED NOT NULL,
  `sender_type` ENUM('customer', 'seller') NOT NULL DEFAULT 'customer',
  `type` ENUM('text', 'image', 'voice', 'product') NOT NULL DEFAULT 'text',
  `content` TEXT NULL DEFAULT NULL,
  `product_id` BIGINT UNSIGNED NULL DEFAULT NULL,
  `file_url` VARCHAR(2048) NULL DEFAULT NULL COMMENT 'Public URL for image or voice note',
  `voice_duration` INT UNSIGNED NULL DEFAULT NULL COMMENT 'Duration in seconds',
  `waveform` JSON NULL DEFAULT NULL COMMENT 'Normalized amplitude values [0.0 - 1.0]',
  `status` ENUM('sending', 'sent', 'delivered', 'read') NOT NULL DEFAULT 'sent',
  `read_at` TIMESTAMP NULL DEFAULT NULL,
  `created_at` TIMESTAMP NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  INDEX `idx_chat_history` (`chat_id`, `created_at` DESC, `id` DESC),
  CONSTRAINT `fk_messages_chat` FOREIGN KEY (`chat_id`) REFERENCES `chats` (`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

3. RESTful API Endpoints

Base URL: https://api.troond.com/api/ • Header: Authorization: Bearer <USER_TOKEN>

POST /api/customer/chats — Initialize or Get Existing Chat

Retrieves an existing chat between customer and seller, or creates a new one.

Request: 
{
  "seller_id": 14,
  "product_id": 1025
}
Response (200 / 201): 
{
  "status": true,
  "data": {
    "id": 85,
    "seller_id": 14,
    "seller": {
      "id": 14,
      "name": "Smart Tech Store",
      "logo": "https://api.troond.com/storage/sellers/14.png",
      "rating": 4.8,
      "rating_count": 28,
      "is_verified": true,
      "is_online": true
    },
    "product": {
      "id": 1025,
      "title": "Wireless Pro Headphones",
      "price": "249.00 SAR",
      "image": "https://api.troond.com/storage/products/1025.jpg"
    },
    "unread_count": 0
  }
}
GET /api/customer/chats/{chat_id}/messages — Fetch Chat Messages
Response (200 OK): 
{
  "status": true,
  "data": [
    {
      "id": 401,
      "chat_id": 85,
      "sender_id": 501,
      "is_me": true,
      "type": "text",
      "content": "Hello, is this item available?",
      "file_url": null,
      "voice_duration": null,
      "status": "read",
      "created_at": "2026-10-26T10:05:00Z"
    }
  ]
}
POST /api/customer/chats/{chat_id}/messages — Send Text Message
Request: 
{
  "content": "Can you provide a discount for 2 items?",
  "type": "text",
  "product_id": 1025
}
Response (201 Created): 
{
  "status": true,
  "data": {
    "id": 403,
    "chat_id": 85,
    "sender_id": 501,
    "type": "text",
    "content": "Can you provide a discount for 2 items?",
    "product_id": 1025,
    "status": "sent",
    "created_at": "2026-10-26T10:10:00Z"
  }
}
POST /api/customer/chats/{chat_id}/files — Upload & Send Image (Multipart)

Content-Type: multipart/form-data • Fields: file (binary), type="image", caption (optional string)

Response (201 Created): 
{
  "status": true,
  "data": {
    "id": 404,
    "chat_id": 85,
    "sender_id": 501,
    "type": "image",
    "file_url": "https://api.troond.com/storage/chats/img_404.jpg",

    "status": "sent",
    "created_at": "2026-10-26T10:15:00Z"
  }
}
POST /api/customer/chats/{chat_id}/voice — Upload & Send Voice Note (Multipart)

Content-Type: multipart/form-data • Fields: voice (binary .m4a/.aac), duration (int seconds), type="voice"

Response (201 Created): 
{
  "status": true,
  "data": {
    "id": 405,
    "chat_id": 85,
    "sender_id": 501,
    "type": "voice",

  }

PATCH /api/customer/chats/{chat_id}/read — Mark Messages as Read
Response (200 OK): 
{
  "status": true,
  "message": "Messages marked as read",
  "unread_count": 0
}

4. Real-Time WebSockets (Pusher / Reverb / Socket.io)

Private Channel: private-chat.{chat_id}

Event Name Trigger Broadcast Payload
message.sent When any participant sends a message Full message JSON object (same as message response)
message.read When recipient opens the chat {"chat_id": 85, "read_by": 14, "read_at": "..."}
user.typing When typing inside input box {"chat_id": 85, "user_id": 501, "is_typing": true}
user.presence When user connects or disconnects {"user_id": 14, "status": "online"}
