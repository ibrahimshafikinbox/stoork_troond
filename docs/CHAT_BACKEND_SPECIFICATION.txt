TROOND CHAT SYSTEM - BACKEND SPECIFICATION (API & DATABASE)
Platform: Troond E-Commerce App
Language: English
================================================================================

1. OVERVIEW & FLOW
------------------
The Troond Chat system allows real-time 1-on-1 messaging between a Customer 
(Mobile User) and a Seller/Merchant.

Supported Message Types:
  - text           : Standard text messages.
  - productInquiry : Text message with attached product context (title, price, image).
  - image          : Pictures uploaded from camera or gallery.
  - voice          : Audio voice notes (.m4a/.aac/.mp3) with duration and waveform.

Message Statuses:
  sending -> sent -> delivered -> read


2. DATABASE SCHEMA (SQL)
------------------------
TABLE 1: chats
-----------------
CREATE TABLE `chats` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `customer_id` BIGINT UNSIGNED NOT NULL,
  `seller_id` BIGINT UNSIGNED NOT NULL,
  `product_id` BIGINT UNSIGNED NULL DEFAULT NULL,
  `last_message_id` BIGINT UNSIGNED NULL DEFAULT NULL,
  `last_message_at` TIMESTAMP NULL DEFAULT NULL,
  `unread_customer_count` INT UNSIGNED NOT NULL DEFAULT 0,
  `unread_seller_count` INT UNSIGNED NOT NULL DEFAULT 0,
  `status` ENUM('active', 'archived', 'blocked') NOT NULL DEFAULT 'active',
  `created_at` TIMESTAMP NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at` TIMESTAMP NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `unique_chat` (`customer_id`, `seller_id`),
  INDEX `idx_customer_inbox` (`customer_id`, `last_message_at` DESC),
  INDEX `idx_seller_inbox` (`seller_id`, `last_message_at` DESC)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

TABLE 2: chat_messages
----------------------
CREATE TABLE `chat_messages` (
  `id` BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `chat_id` BIGINT UNSIGNED NOT NULL,
  `sender_id` BIGINT UNSIGNED NOT NULL,
  `sender_type` ENUM('customer', 'seller') NOT NULL DEFAULT 'customer',
  `type` ENUM('text', 'image', 'voice', 'product') NOT NULL DEFAULT 'text',
  `content` TEXT NULL DEFAULT NULL,
  `product_id` BIGINT UNSIGNED NULL DEFAULT NULL,
  `file_url` VARCHAR(2048) NULL DEFAULT NULL,
  `voice_duration` INT UNSIGNED NULL DEFAULT NULL,
  `waveform` JSON NULL DEFAULT NULL,
  `status` ENUM('sending', 'sent', 'delivered', 'read') NOT NULL DEFAULT 'sent',
  `read_at` TIMESTAMP NULL DEFAULT NULL,
  `created_at` TIMESTAMP NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  INDEX `idx_chat_history` (`chat_id`, `created_at` DESC, `id` DESC),
  CONSTRAINT `fk_messages_chat` FOREIGN KEY (`chat_id`) REFERENCES `chats` (`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;


3. RESTFUL API ENDPOINTS
-------------------------
Base URL: https://api.troond.com/api/
Auth: Bearer Token (Header: Authorization: Bearer <USER_TOKEN>)

ENDPOINT 1: Initialize or Get Chat
POST /api/customer/chats
Request:
{
  "seller_id": 14,
  "product_id": 1025
}
Response (200 / 201):
{
  "status": true,
  "data": {
    "id": 85,
    "seller_id": 14,
    "seller": {
      "id": 14,
      "name": "Smart Tech Store",
      "logo": "https://api.troond.com/storage/sellers/14.png",
      "rating": 4.8,
      "rating_count": 28,
      "is_verified": true,
      "is_online": true
    },
    "product": {
      "id": 1025,
      "title": "Wireless Pro Headphones",
      "price": "249.00 SAR",
      "image": "https://api.troond.com/storage/products/1025.jpg"
    },
    "unread_count": 0
  }
}

ENDPOINT 2: Get Chat Messages
GET /api/customer/chats/{chat_id}/messages
Response (200):
{
  "status": true,
  "data": [
    {
      "id": 401,
      "chat_id": 85,
      "sender_id": 501,
      "is_me": true,
      "type": "text",
      "content": "Hello, is this product available in black?",
      "file_url": null,
      "voice_duration": null,
      "status": "read",
      "created_at": "2026-10-26T10:05:00Z"
    }
  ]
}

ENDPOINT 3: Send Text Message
POST /api/customer/chats/{chat_id}/messages
Request:
{
  "content": "Can you provide a discount for 2 items?",
  "type": "text",
  "product_id": 1025
}
Response (201):
{
  "status": true,
  "data": {
    "id": 403,
    "chat_id": 85,
    "sender_id": 501,
    "type": "text",
    "content": "Can you provide a discount for 2 items?",
    "product_id": 1025,
    "status": "sent",
    "created_at": "2026-10-26T10:10:00Z"
  }
}

ENDPOINT 4: Upload & Send Image
POST /api/customer/chats/{chat_id}/files
Content-Type: multipart/form-data
Fields:
  - file    : binary image (jpg, png, webp)
  - type    : "image"
  - caption : optional text string
Response (201):
{
  "status": true,
  "data": {
    "id": 404,
    "chat_id": 85,
    "sender_id": 501,
    "type": "image",
    "file_url": "https://api.troond.com/storage/chats/img_404.jpg",
    "content": "Is this the exact model?",
    "status": "sent",
    "created_at": "2026-10-26T10:15:00Z"
  }
}

ENDPOINT 5: Upload & Send Voice Note
POST /api/customer/chats/{chat_id}/voice
Content-Type: multipart/form-data
Fields:
  - voice    : binary audio file (.m4a, .aac, .mp3)
  - duration : integer (duration in seconds, e.g. 14)
  - type     : "voice"
Response (201):
{
  "status": true,
  "data": {
    "id": 405,
    "chat_id": 85,
    "sender_id": 501,
    "type": "voice",
    "file_url": "https://api.troond.com/storage/chats/voice_405.m4a",
    "voice_duration": 14,
    "waveform": [0.2, 0.4, 0.8, 0.6, 0.9, 0.3, 0.7, 0.5],
    "status": "sent",
    "created_at": "2026-10-26T10:18:00Z"
  }
}

ENDPOINT 6: Mark Messages as Read
PATCH /api/customer/chats/{chat_id}/read
Response (200):
{
  "status": true,
  "message": "Messages marked as read",
  "unread_count": 0
}


4. REAL-TIME WEBSOCKETS (Pusher / Socket.io / Laravel Reverb)
------------------------------------------------------------
Private Channel: private-chat.{chat_id}

Broadcast Events:
  - message.sent    : Triggered on new message. Payload: complete message object.
  - message.read    : Triggered when recipient opens chat. Payload: {"chat_id": 85, "read_by": 14}
  - user.typing     : Triggered when typing. Payload: {"chat_id": 85, "user_id": 501, "is_typing": true}
  - user.presence   : Triggered on connection status. Payload: {"user_id": 14, "status": "online"}
